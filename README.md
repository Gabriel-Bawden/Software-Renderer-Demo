# Software Renderer

## Overview

This program consists of a software renderer along with a custom-made GUI library for manipulating the scene. The user can create a scene consisting of the provided 3D models. Textures and normal maps may also be applied to these models, and the models' materials may be altered as well. The user may also alter the scene's lighting. The GUI consists of a font renderer along with elements such as textboxes, buttons, checkboxes, sliders, and tabs.

## Controls

Note that the camera cannot be moved while the GUI is visible.

| Key | Action |
| :---: | :---: |
| S | Move backwards |
| W | Move forwards |
| A | Move left |
| D | Move right |
| Left Shift | Move down |
| Space | Move up |
| Escape | Toggle GUI |
| Enter | Reset position |
| Escape | Toggle GUI |
| Mouse | Move camera |
